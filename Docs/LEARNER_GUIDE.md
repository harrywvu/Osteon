# Osteon learner guide

Osteon supports skeletal inspection from the complete skeleton to individual
bones. Anatomy exploration, display settings, and the Field Guide are available
before sign-in. The practice quiz requires an internet connection and a learner
account.

## Explore the skeleton

1. Select the axial or appendicular division on the full skeleton.
2. Select a bone group, such as the skull, ribcage, or a limb. Where available,
   use the **Spread** slider to separate bones and make individual bones easier
   to select.
3. Hover over a bone to see its name, then select it to inspect an enlarged copy.
   The adjacent assembled model shows the bone's anatomical position.
4. Select **Back** to return to the group. Continue back through the division
   to the full skeleton.

| Action | Quest controllers | Desktop browser |
|---|---|---|
| Select anatomy or a panel control | Aim the controller ray and select | Point and left-click with the cursor free |
| Rotate a skeleton or group | Move the right stick sideways | Right-drag horizontally or use Left/Right Arrow |
| Turn or tilt the inspected bone | Move the right stick horizontally or vertically | Right-drag or use the arrow keys |
| Reset turn or tilt | **A** for turn, **B** for tilt | **R** for turn, **T** for tilt |
| Go back | Left **X** or panel **Back** | **Backspace** or panel **Back** |
| Move a panel | Grab and drag its blue **Move** bar | Left-drag its blue **Move** bar |

The Field Guide provides instructions within the application. To release the cursor after
using mouse look, press **F**, **Tab**, or **Esc**. See the
[desktop control reference](WEB_DESKTOP.md#controls) for room movement.

## Practice quiz and display settings

- Open the quiz station and choose **Accounts**. Create a learning profile or
  enter an existing six-digit code. Store the code securely for use after an
  application restart or when switching devices. On Quest, select a profile text
  field to open the in-world keyboard.
- Start or resume the quiz, select an answer, read the feedback, and choose
  **Next** to continue.
- Open **Settings** to change the room colors, panel theme, text size, or bone
  highlight color. Preferences are saved on the device or browser profile.
- Select **Read** on a panel to hear its text and **Stop** to end playback. The
  browser plays bundled recordings. Quest can also use a device voice for text
  without a recording.
